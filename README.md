# Two-Sentence Horror

[![make.fun](https://make.fun/badge/u-suroto-two-sentence-horror-acea9253.svg)](https://make.fun/c/u-suroto-two-sentence-horror-acea9253)

Entry for the [Two-Sentence Horror](https://make.fun/c/u-suroto-two-sentence-horror-acea9253) bounty on make.fun.

## What it does

`main.ts` writes one deterministic horror story of exactly two sentences
(229 characters, well under the 400-character limit) to `/output/entry.txt`
and prints it to stdout. No input, no randomness, no network — the same
story every run.

## The story

> I've lived alone for six years, and every night I lock all three deadbolts before bed. Last night I woke up to the third one unlocking itself, and a voice exactly like mine whispering from the hallway: 'Don't worry, I live here too'

## Run

```sh
node main.ts
```
